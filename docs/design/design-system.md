# 디자인 시스템과 UI/UX

> 이 문서는 [perfect-vibe-coding](https://github.com/paakseongjin/perfect-vibe-coding)의 디자인 규칙입니다.  
> 시각 토큰(색·크기·반경)의 SSOT는 `TYPEGUIDE.md`와 `world-manager/styles/tokens.css`입니다.

## 1. 디자인 시스템 우선

- 모든 UI는 개별 페이지의 임의 스타일이 아니라 공통 디자인 시스템을 기반으로 구현한다.
- 색상, 타이포그래피, 간격, 그리드, 반경, 그림자, 아이콘, 모션, 상태 표현은 디자인 토큰으로 관리한다.
- 버튼, 입력창, 드롭다운, 체크박스, 모달, 테이블, 카드, 알림 등 반복 요소는 재사용 가능한 컴포넌트 규격을 우선 사용한다.
- 인라인 스타일, 페이지 전용 임의 색상값, 중복 CSS, 의미 없는 클래스명 생성을 최소화한다.
- 동일한 기능과 상태는 모든 화면에서 같은 용어, 컴포넌트, 색상 의미, 인터랙션 방식으로 표현한다.
- **레이아웃은 고정 골격(헤더·단계·레일·본문·상태줄)과 8px 리듬을 유지한다.** (`TYPEGUIDE.md`)

## 2. 디자인 문서 운영

- `docs/design/` 또는 동등한 디자인 가이드 공간을 운영한다.
- 디자인 가이드에는 아래 내용을 기록하고 최신화한다.

  - 브랜드 및 제품 디자인 원칙
  - 컬러 토큰과 사용 금지 사례
  - 타이포그래피 체계와 한글 조판 기준
  - 여백, 그리드, 반응형 브레이크포인트
  - 컴포넌트별 상태와 사용 방법
  - 아이콘, 이미지, 일러스트레이션 사용 원칙
  - 폼 입력, 오류, 빈 상태, 로딩, 성공, 경고 상태
  - 접근성 기준과 키보드 사용 규칙
  - 화면별 패턴 및 구현 예시
  - 변경 이력과 적용 범위

- 디자인 시스템을 변경하면 영향을 받는 컴포넌트와 화면을 점검하고, 관련 문서와 운영 맵을 함께 갱신한다.

## 3. 포커스·선택 테두리 (1겹)

클릭·탭·키보드로 활성화된 요소의 **색 테두리는 항상 1겹**이다.

- 토큰: `--focus-border` (`var(--primary)`). `--focus-ring`은 쓰지 않는다 (`none`).
- 구현: `outline: none` + 그림자 고리 없음 + `border: 1px solid var(--focus-border)` 한 줄만. (`border: var(--line)` 단축은 `border-color`만으로 안 바뀌는 경우가 있어, 포커스에선 테두리 전체를 다시 적는다.)
- 테두리가 없던 버튼·링크는 평소 `1px solid transparent`를 두고, 포커스 때 그 선만 보이게 한다.
- 금지: `outline`과 `border-color`를 같이 켜기, `box-shadow: 0 0 0 1px`를 테두리 밖에 한 겹 더 그리기.
- 선택됨(`.is-selected` / `.is-active`)도 같다. 색 선 1겹만.
