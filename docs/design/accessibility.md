# 접근성과 표준

## 1. 기본 원칙

- 웹 구현은 HTML 시맨틱 구조, 키보드 조작, 명확한 포커스 표시, 충분한 색상 대비, 대체 텍스트, 오류 안내를 기본값으로 한다.
- 최신 W3C WCAG 2.2 기준을 참고하여 접근성을 구현한다. WCAG는 장애 유무와 관계없이 웹 사용성을 높이는 국제 접근성 지침이다.
- 표준을 따르되, 프로젝트의 실제 사용자·기기·운영 환경에 맞지 않는 패턴은 그대로 도입하지 않는다.

## 2. 키보드·포커스

- 클릭 가능한 요소는 키보드로도 조작 가능해야 하며, 포커스가 가려지거나 사라지지 않아야 한다.
- 모달, 드롭다운, 메뉴 등 오버레이 UI는 포커스 트랩과 닫기 경로를 명확히 제공한다.

## 3. 색상·상태·반응형

- 색상만으로 상태나 오류를 전달하지 않는다. 텍스트, 아이콘, 형태 등 보조 단서를 함께 사용한다.
- 반응형 레이아웃은 작은 화면부터 큰 화면까지 콘텐츠 우선순위와 조작성을 유지해야 한다.
- 작업 후 검증 시 키보드 조작, 포커스, 오류 메시지, 접근성 기본 동작을 확인한다.
