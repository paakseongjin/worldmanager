# 한글 타이포그래피

## 1. 문서와 토큰

- 타이포그래피 체계와 한글 조판 기준은 `TYPEGUIDE.md` 또는 `docs/design/`의 동등한 문서에 단일 진실 공급원으로 유지한다.
- 폰트 패밀리, 크기, 행간, 자간, 가중치는 디자인 토큰으로 관리한다.
- 페이지별 임의 폰트·크기·행간 지정을 최소화하고, 공통 토큰·유틸리티를 우선 사용한다.

## 2. 한글 조판 원칙

- 한글과 영문이 혼용될 때 가독성, 정렬, 행간이 깨지지 않도록 조판한다.
- 제목·본문·캡션·버튼·폼 라벨 등 역할별 타이포 스케일을 일관되게 적용한다.
- 줄바꿈, 말줄임, 긴 한글 단어·주소·고유명사 처리에서 레이아웃이 붕괴되지 않게 한다.
- 반응형 화면에서도 본문 가독성과 터치/클릭 가능 영역의 텍스트 크기를 유지한다.

## 3. 변경 시 점검

- 타이포 토큰이나 폰트를 변경하면 주요 화면의 제목·본문·폼·알림 상태를 점검한다.
- 관련 디자인 문서와 운영 맵을 함께 갱신한다.
- 전체 배율은 `tokens.css`의 `--wm-type-scale`(기본 1.2)로 조절한다.
